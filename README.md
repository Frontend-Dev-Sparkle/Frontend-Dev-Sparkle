## 🔭 What I'm Working On

> **Humantic — Guard & Security Intelligence Platform** · *Multiplied AI*

A React Native app that captures field signals (shift start/end, breaks, and photo/video/audio notes tied to incidents) for guards on the ground.

- ⚡ **Offline-first** capture with a background upload queue using **WatermelonDB** and pull-based sync
- 🔴 **Real-time UI** driven by backend events over **SSE**
- 🔗 **GraphQL** queries & mutations backed by **PostgreSQL**
- 🧠 Feeds AI agents that classify activity across mobile, walkie-talkie, WhatsApp, SMS, and email, then auto-generate **daily activity reports**
